# Curbcut

An interactive product concept created by Maya and Theo in [Cofounder Live](https://nano-banana-guide-26967920041.us-central1.run.app).

## Product

A high-contrast, data-precise neighborhood guide with a built-in High-Contrast & Text-Scaling Toggle, helping active wheelchair users navigate local culture with absolute certainty.

- Revision: 2
- Google capability: Google Maps
- Capability rationale: Allows active rollers to visualize exact physical entry points, ramp slopes, and accessible pathways on a custom high-contrast map before arriving.

## Run locally

Open `index.html` in a modern browser. The interface has no build step.

The Google Maps interaction uses the hosted Cofounder Live runtime for mission `ep_mta8mzku` when a server-side Google Cloud action is required.
